# F0 — Project foundation

Approved scope: scaffold a Kotlin Multiplatform + Compose puzzle app, separate
modules/dependencies, configure Android/iOS debug builds and CI quality gates.

- `engine`: pure Kotlin shared module, JVM and iOS targets; no UI dependencies.
- `composeApp`: shared Material 3 placeholder UI, Android application and iOS framework.
- `iosApp`: SwiftUI host and checked-in Xcode project, consuming the shared framework.
- Central version catalog; Gradle wrapper with distribution checksum.
- Android min SDK 24, compile/target SDK 36; iOS deployment target 15.0.
- Linux CI: engine JVM tests, Kotlin formatting, Android lint and debug APK.
- macOS CI: iOS simulator test and unsigned simulator debug app build.

No game logic, persistence, network, ads or purchases in F0. No credentials or
backend services required. Linux cannot validate Xcode or Kotlin/Native Apple
linking; these must run on macOS CI. No push or release is part of this task.

Alternatives considered: one combined module is simpler but couples future engine
tests to UI; separate native UIs duplicate F2 work. Approved choice: pure engine
and shared Compose UI with thin native entry points.
