# F2 Play UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** Connect the approved light Compose UI to F1 with accessible touch/drag play.
**Architecture:** Pure geometry, injected-clock presentation controller, shared screens, lifecycle/ViewModel adapter.
**Tech Stack:** Existing KMP/Compose, JetBrains lifecycle Compose 2.9.4, Robolectric.
**Spec:** docs/superpowers/specs/2026-10-31-f2-play-design.md

## Global Constraints
- Preserve F0/F1 changes and game rules; no additional worktree or push.
- Home/game screens in commonMain; no persistence/backend/ads.
- Pausing/background must freeze time, cancel gestures and require resume.
- Tap and drag must use identical engine placement validation.

## Review Focus
- Elapsed time must be consumed before moves, preventing late moves avoiding timeout.
- Exit cancellation must preserve prior paused/active status.
- Drag coordinate mapping must account for root offset, anchor and zoom scroll clipping.
- Invalid/outside/cancelled drags must never consume a piece.
- Configuration change must retain session while background time stays frozen.
