# F1 Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement configurable deterministic puzzle rules and timed difficulty modes.
**Architecture:** Immutable value models, seeded piece generator, immutable game session transitions.
**Tech Stack:** Kotlin Multiplatform 2.2.20, kotlin.test, Gradle 8.14.3.
**Spec:** docs/superpowers/specs/2026-10-30-f1-engine-design.md

## Global Constraints
- Preserve all F0 work; use existing checkout without another worktree.
- Pure common Kotlin; no runtime platform dependencies or wall clock.
- Support 8×8/16×16 independently of difficulty/tempo.
- Three timeout strikes; 10-point penalty floored at zero.
- Relaxed/no limit, Slow90s, Medium45s, Fast20s.

## Review Focus
- Row/column intersections clear simultaneously with no double cell counting.
- Rejected moves cannot change RNG, hand, score or time.
- Large elapsed-time updates reach third strike without overflow or loops.
- Caller-owned collections cannot mutate engine snapshots.
- Apple common tests must run in CI, alongside the existing launch test.
