# BlockPuzzle2026

Cross-platform 8x8 block puzzle game for Android and iOS.

## Stack
- Kotlin Multiplatform + Compose Multiplatform
- Shared deterministic Kotlin game engine
- Android Studio + Xcode

## Roadmap
1. Bootstrap KMP Android/iOS project
2. Implement board, pieces, placement, line clearing and scoring with tests
3. Compose game UI and drag/drop
4. Persistence, leaderboard, ads and purchases

## Game rules
Place one of three available pieces on an 8x8 grid. Completed rows and columns clear simultaneously. The game ends when none of the available pieces can fit.
